# Fashion Shop Fullstack

Production-ready scaffold for a Fashion Shop project.

## Stack

- Frontend: React, Vite, React Router DOM, Tailwind CSS, Axios, Redux Toolkit
- Backend: Node.js, Express.js, MongoDB, Mongoose
- Auth: JWT access token and refresh token
- Payment: SePay QR Banking and webhook callback
- Upload: Multer and Cloudinary

## Structure

- `frontend/`: customer and admin React app organized by features.
- `backend/`: Express API using MVC plus service layer.
- `docs/`: API, webhook, and deployment notes.
